# my-first-website
I used WAVE accessibility checker to test all three pages of my website: Home, Projects, and About. All three showed zero errors and zero contrast errors. I did not need to make any accessibility fixes because my pages passed the WAVE check.
Proximity: I used proximity by keeping related information and project cards close together. This makes my website easier to read and understand.
Similarity: I used similarity by keeping the same colors, fonts, and styles across my Home, Projects, and About pages. This makes my website look organized and consitent.
Accessible Contact Form: I added a contact form to my About/Contact page. The form includes a name field, email field, message box, and submit button. I used proper labels, a fieldset, a legend, and required fields to make the form more accessible.
